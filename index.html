SuperTux Remastered
An independent hobbyist remaster of SuperTux 2 — native Vulkan, DirectX 12, Metal, and WebGPU renderer.

Download & Play

Rolling test builds from main. Native GPU renderer on every platform. Original SuperTux artwork. Zero translation layers.

Experimental
Alpha — WebGPU / WASM
Download installer / portable build Play in Browser (WebGPU / WASM)
⚠️ WebGPU / WASM port is experimental and alpha-stage.
Requires a browser with WebGPU support (Chrome/Edge 113+, Firefox with dom.webgpu.enabled). Shader compilation runs on first load for stability. Please report issues with your browser version and any console errors.

Platforms

🐧 Linux

Native Vulkan renderer via SDL_GPU. Portable tarball — extract and run. SDL3 + OpenAL system libraries required.

🪟 Windows

Native DirectX 12 with Vulkan fallback. Portable ZIP. Unsigned test builds — SmartScreen may warn.

🍎 macOS

Native Metal renderer (universal2: Apple Silicon + Intel). Universal .app bundle. Right-click → Open on first launch.

🌐 Browser

WebGPU / WASM port via Emscripten. Runs instantly in the browser — no installation needed. Experimental alpha.

Command line (advanced users)

If you prefer the terminal, test builds are also available as portable archives. Download, extract, and run the supertux2 binary directly. Full build instructions are in INSTALL.md.
